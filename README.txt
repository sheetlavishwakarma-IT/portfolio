# Portfolio — Sheetla Vishwakarma

A personal portfolio website built with plain HTML, CSS and JavaScript. It has a dark theme with a lime accent, an "Enter" gate with background music, and smooth scroll animations.

**Live site:** https://sheetlavishwakarma-it.github.io/portfolio/

## Features

- Enter gate that opens the site and starts the intro song (with a mute button)
- Scroll progress bar and active navigation highlight
- Scroll-reveal animations, cursor glow and floating cards
- Sections: Home, Intro, Services, Selected Work, Journey, Contact
- Responsive layout for phones and desktops
- Respects `prefers-reduced-motion` for accessibility

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Archivo, Instrument Serif)

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/sheetlavishwakarma-IT/portfolio.git
   ```
2. Open the folder and double-click `index.html`.

No build tools or installation needed.
